OUR LITTLE STORY — BIRTHDAY WEBSITE

Included:
- index.html
- css/style.css
- js/story.js (editable chapter text and screenshot captions)
- js/app.js (page-turn, birthday card, private letter, music control)
- images/memory-01.jpg through memory-06.jpg (the six screenshots you supplied)
- music/ (put your own bgm.mp3 here)

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser. For best results, use a small local server or GitHub Pages.
3. On GitHub, upload the contents of this folder to your repository root, then enable GitHub Pages in repository Settings > Pages.

HOW TO PERSONALIZE
- Edit chapter wording in js/story.js.
- Replace screenshots in images/ while keeping the same filenames, or change the image paths in js/story.js.
- Add a music file named bgm.mp3 to music/. Browsers usually require the visitor to tap the Music button before playback.
- The private letter is in index.html, inside #letterModal.

PRIVACY
This is a static website. Anyone who can access the published page can view its contents and included screenshots. Do not upload private screenshots or identifying details unless you are comfortable sharing them with anyone who has the link. GitHub Pages does not provide password protection for a normal public page.
